# Zee9 — S9 Game Clone (Demo)

Landscape-only gaming platform demo matching **S9 Game** UI from reference screenshots.

## Run

```bash
npm install
npm run dev
```

Open in **landscape mode** (rotate phone horizontally). Portrait mode auto-rotates the view.

## Features

- Full-screen S9 lobby using original reference screenshots
- Sidebar category switching (HOT, LOVE, GAMES, SLOT, LIVE, CARD, SPORTS, ALL)
- Tap game tiles to open play screen
- Refer & Earn / Add Cash tap zones
- Landscape-only — no vertical layout

## Flow

Splash → Lobby (S9 UI) → Tap game → Play screen → Back to Lobby

Screenshots in `public/s9/` (ref1–ref4) from S9 Game app.
